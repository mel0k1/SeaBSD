SeaBSD — десктоп-первая операционная система, построенная на фундаменте [FreeBSD](https://www.freebsd.org). Проект отталкивается от простого наблюдения: наследники BSD славятся надёжностью на серверах, но никто всерьёз не поставляет их обычным пользователям компьютеров. SeaBSD меняет приоритеты местами — тот же монолитно надёжный базис, но настроенный под ноутбуки, рабочие станции и повседневные задачи.

## Почему SeaBSD?

FreeBSD уже решает сложные задачи: целостная базовая система, ZFS, Jails, чистый сетевой стек и дерево исходников, которое собирается целиком от начала до конца. Не хватает пользовательского слоя. SeaBSD делает ставку на три кита:

1. **Железо просто работает.** Автоопределение, поддерживаемая база совместимости и честная документация о том, что работает из коробки: Wi-Fi, видеокарты, звук, веб-камеры.
2. **Linux-софт — лучше.** Слой совместимости с Linux в FreeBSD (*linuxolator*) мощный, но шероховатый на краях. SeaBSD вкладывается в тесты, тюнинг и упаковку, чтобы Linux-приложения были полноправными гражданами системы, а не костылём.
3. **Живучие песочницы.** В будущих релизах одноразовые окружения станут дешёвыми: сломанную песочницу можно сбросить до чистого состояния за секунды через ZFS-снапшоты — без настройки всего с нуля.

## Статус проекта

SeaBSD находится на **предальфа-этапе каркаса**. В репозитории сейчас лежит устав проекта, роадмап, черновики сборочного фреймворка и CI. Устанавливаемого образа ещё нет — первая веха описана в [ROADMAP.md](ROADMAP.md).

## Сборка из исходников

Для сборки образа SeaBSD нужен хост с FreeBSD 14.x (или виртуальная машина):

```sh
git clone https://github.com/mel0k1/SeaBSD.git
cd SeaBSD
sh build/build-iso.sh
```

Переменные окружения, требования к диску и описание этапов сборки — в [build/README.md](build/README.md).

## Участие в проекте

На этом раннем этапе вклад особенно ценен, в первую очередь:

- отчёты о железе с реальных машин (`tools/hwcheck.sh` на FreeBSD),
- тесты совместимости linuxolator и разбор багов,
- документация, переводы, дизайн.

С чего начать — читайте [CONTRIBUTING.md](CONTRIBUTING.md).

## Лицензия

SeaBSD распространяется по лицензии **BSD 3-Clause** — той же, что использует upstream FreeBSD, поэтому код может свободно двигаться между проектами. См. [LICENSE](LICENSE).
